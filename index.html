Project Blox
Lua API

The current Psych-style bridge for Project Blox chart scripts. Scripts execute inside AegisVM with a restricted environment, explicit bridge functions, safe gameplay properties and chart callbacks.

Getting started

Chart scripts are callback-driven. The bridge starts onCreate, onCreatePost and onSongStart, then updates while gameplay is active.

local announced = false

function onUpdate(elapsed)
    if not announced and getSongPosition() >= 5000 then
        announced = true
        debugPrint('Five seconds reached')
    end
end
getSongPosition() and getSongLength() return milliseconds. elapsed is seconds.

Called after a bridge tween completes.

Timer

Called by runTimer for each completed loop.

Event

onEvent(name, value1, value2)

Runs when the runtime is destroyed or gameplay exits.

Objects & properties

The safe resolver supports engine aliases and objects found inside GameplayUI. Property availability still depends on the resolved target.

camHUD

HUD virtual offsets and alpha driver. Designed so gameplay updates do not overwrite modchart offsets.

camGame

Main camera alias; zoom maps to the safe camera/FOV driver.

boyfriend / bf

Player sprite aliases.

dad / opponent

Opponent sprite aliases.

Safe property allowlist includes x, y, width, height, alpha, visible, angle, scaleX, scaleY, text, zIndex, color, anchorX, anchorY, image, textSize, backgroundAlpha and zoom.

Strum groups

playerStrums

Indexes 0–3 → MyLane0–MyLane3.

opponentStrums

Indexes 0–3 → EnemyLane0–EnemyLane3.

strumLineNotes

0–3 = opponent; 4–7 = player.

Allowed Lua

Pure primitives/libraries are re-injected into the noStdLib sandbox: tostring, tonumber, type, typeof, pairs, ipairs, next, select, assert, error, pcall, xpcall, math, string, table, bit32, utf8.

Tweens & easings

Tween tags are reusable; a new tween with the same tag replaces the previous one. Completion calls onTweenCompleted(tag).

Sandbox & limits

AegisVM

Sandbox is created with noStdLib=true and maxCallDepth=100.

No Roblox internals

Chart scripts do not receive raw game, workspace, Instances or unrestricted services through the public bridge.

Up to 8 scripts

The current loader processes a maximum of eight chart scripts.

Failsafe

Compile/runtime failures are reported without making chart scripts mandatory for gameplay.

Whitelist ≠ implementation. Use the status column in the API table to distinguish working bridge functions from compatibility names that are only exposed today.

Practical examples

HUD jump

function onBeatHit()
    doTweenY('hudUp', 'camHUD', -10, 0.27, 'circOut')
end

function onTweenCompleted(tag)
    if tag == 'hudUp' then
        doTweenY('hudDown', 'camHUD', 0, 0.27, 'sineIn')
    end
end

Timer

function onSongStart()
    runTimer('warning', 2, 1)
end

function onTimerCompleted(tag, loops, loopsLeft)
    if tag == 'warning' then
        debugPrint('Two seconds passed')
    end
end

Random receptor angle

function onBeatHit()
    local angle = getRandomInt(-12, 12)
    noteTweenAngle('laneSpin', 4, angle, 0.2, 'quadOut')
end
